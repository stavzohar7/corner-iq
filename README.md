# 🚩 קורנר IQ — ניתוח קרנות יומי

אתר ציבורי שכל יום מנתח את משחקי היום ב-11 ליגות, ומדרג הימורי קרנות מ-1 עד 10 לפי סגנון המשחק של הקבוצות, בית/חוץ, היריבה, ויחסי Bet365.

**ליגות:** פרמייר ליג, צ׳מפיונשיפ, לה ליגה, סרייה A, בונדסליגה, בונדסליגה 2, ליגת העל, ליגה לאומית, ליג 1, ארדיביזי, ליגה פורטוגל.

## איך זה עובד

- `scripts/update.mjs` רץ כל בוקר ב-GitHub Actions. הוא מושך מ-[API-Football](https://www.api-football.com) את משחקי היום, את הסטטיסטיקות של כל משחקי העונה (קרנות, בעיטות, החזקת כדור) ואת יחסי Bet365 לשווקי הקרנות.
- `scripts/model.mjs` בונה לכל קבוצה פרופיל בית/חוץ, מחשב צפי קרנות ומדרג כל הימור.
- האתר (`index.html` + `assets/`) מתפרסם אוטומטית ב-GitHub Pages, חינם, וכל אחד יכול להיכנס בלינק.
- למחרת, כל בחירה נבדקת מול התוצאה. בלשונית "מעקב הצלחה" רואים כמה כל דירוג פוגע בפועל.

## הקמה (פעם אחת, כ-10 דקות)

1. **מפתח API:** נרשמים ב-https://dashboard.api-football.com ומעתיקים את ה-API Key.
   - בתוכנית החינמית יש 100 קריאות ביום. זה מספיק לשימוש יומי, אבל המאגר יתמלא בהדרגה במשך 2–3 ימים.
   - חשוב: ייתכן שהתוכנית החינמית לא כוללת את העונה הנוכחית. אם ההרצה נכשלת עם הודעה על "season", צריך לשדרג לתוכנית Pro.
2. **GitHub:** יוצרים ריפו **ציבורי** חדש ומעלים אליו את התיקייה הזו.
3. **סוד:** בריפו נכנסים ל-Settings → Secrets and variables → Actions → New repository secret. שם: `API_FOOTBALL_KEY`, ערך: המפתח.
4. **Pages:** ב-Settings → Pages, תחת Source בוחרים **GitHub Actions**.
5. **הרצה ראשונה:** בלשונית Actions בוחרים את "עדכון יומי + פרסום האתר" ולוחצים **Run workflow**.
6. הכתובת של האתר תופיע ב-Settings → Pages. זה הלינק לשתף.

### הגדרות אופציונליות (Settings → Variables → Actions)
| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `MAX_CALLS` | 95 | מקסימום קריאות API בהרצה. בתוכנית בתשלום אפשר להעלות ל-1000. |
| `RATE_PER_MIN` | 10 | מגבלת קריאות לדקה. בתוכנית בתשלום אפשר 300. |
| `TWICE_DAILY` | – | `true` מוסיף עדכון יחסים בצהריים. מומלץ רק בתוכנית בתשלום. |

## הרצה מקומית

```bash
MOCK=1 node scripts/update.mjs      # נתוני דמו (מומצאים) לבדיקה
API_FOOTBALL_KEY=xxx node scripts/update.mjs   # נתונים אמיתיים
node scripts/serve.mjs               # האתר בכתובת http://localhost:8080
```

## הדירוג (1–10)

- **ערך צפוי:** הסיכוי לפי המודל, מוכפל ביחס של Bet365.
- **גובה הסיכוי:** הימור "רחוק" מקבל פחות.
- **ביטחון בנתונים:** כמה משחקים יש במאגר, האם מודל הקרנות ומודל הבעיטות מסכימים, וכמה הקבוצה יציבה.
- **פער חשוד:** אם המודל רחוק מאוד מ-Bet365, כנראה חסר לו מידע (פציעות, הרכב), והדירוג יורד.

משחק בלי יחס Bet365 מקבל לכל היותר 7 ומציג "יחס הוגן" להשוואה ידנית.

> ⚠️ ניתוח סטטיסטי בלבד ולא הבטחה לרווח. הימרו באחריות. 18+.
