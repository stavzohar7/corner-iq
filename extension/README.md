# קורא fivebet (תוסף Chrome) — התקנה חד פעמית

מה זה עושה: כל יום ב-10:30 (או כשפותחים את Chrome אחרי זה) התוסף פותח חלון קטן בדפדפן שלך, קורא מ-fivebet את יחסי משחקי היום (בלי כניסה לחשבון), ושולח אותם לריפו. GitHub Actions בונה מהם את הטפסים ומפרסם באתר. לא צריך קלוד ולא צריך להיות ליד המחשב, אבל Chrome חייב להיות פתוח (המחשב דלוק).

1. מפתח GitHub: https://github.com/settings/personal-access-tokens/new , בחר Only select repositories ← corner-iq , Permissions ← Contents: Read and write , צור והעתק.
2. ב-Chrome: chrome://extensions ← מצב מפתח ← Load unpacked ← תיקיית extension.
3. לחץ על סמל התוסף, הדבק את המפתח ושמור. לחץ "קרא עכשיו" לבדיקה.
